# done.

Desktopová aplikace pro správu úkolů a projektů určená především pro studenty.

## O aplikaci

**done.** umožňuje efektivní organizaci osobních úkolů a týmových školních projektů. Aplikace klade důraz na jednoduchost, přehlednost a intuitivní ovládání.

## Funkce

- Správa osobních úkolů s termíny, kategoriemi a prioritami
- Správa projektů se systémem rolí vlastník/člen
- Týmová spolupráce – připojení k projektu pomocí kódu
- Kalendářové zobrazení úkolů a projektů
- Fulltextové vyhledávání napříč aplikací
- Nahrávání příloh k projektům
- Kategorizace úkolů a projektů

## Technologie

- **Electron** – desktopový framework
- **HTML, CSS, JavaScript** – uživatelské rozhraní
- **Node.js** – aplikační vrstva
- **Supabase** – backend (PostgreSQL, Auth, Storage)

## Instalace

### Windows
1. Stáhni instalátor z [GitHub Releases](https://github.com/trah15/doneapp/releases/tag/v1.0.0)
2. Spusť `done Setup 1.0.0.exe`
3. Pokud Windows zobrazí varování, klikni na „Více informací" → „Přesto spustit"
